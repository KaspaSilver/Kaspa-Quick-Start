Kaspa Quick Start
Run your own Kaspa node without touching the terminal.

This installs Docker if it is not already present, downloads the Kaspa Quick Start stack, and starts the control panel. You will be asked for your password once so it can install what it needs.

Change this if port 8420 is already used by another app on this machine.

This stops and removes the Kaspa Quick Start containers, images, and control panel. Your synced blockchain and data are kept by default, so you can reinstall quickly. Docker itself is left installed.

    Ports

    Listening means the node has that service switched on. Public opens it up on this machine, and that is the part that decides whether anything outside can reach it. Both start out on. Changing either one restarts the node.

    PortServiceListeningPublicState

    Network

    Switching to a different chain changes all the port numbers and starts a fresh database, so your current one is left untouched.

    Indexes & flags

    “Accept submitted blocks while unsynced” is really only useful for testing. It will not let you mine during a first sync, because the node has a separate check that this setting does not switch off. Even if it did, blocks found against a half-finished copy of the chain get thrown away. Mining stays locked here until the node has caught up.

    KaChat indexer
    
          
    
            Turns this node's chain data into the APIs every KaChat client talks
            to: direct and group chats, broadcasts, KaPosts and mentions. Its own
            dashboard appears below once it is running, with the same Dashboard,
            KaPosts, Broadcasts, Chats, Group chats, Export / Import and Settings
            tabs it always had.
          
    
          
    
            It uses the node you are already running, so nothing has to sync twice.
            The very first start has to build the indexer from source, which takes
            a while. You can watch it happen on the All logs page.
